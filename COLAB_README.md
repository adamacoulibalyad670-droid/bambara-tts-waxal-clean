# Bambara Speech AI

This repository is a starter project for Bambara speech processing with:
- TTS (Text-to-Speech)
- ASR (Automatic Speech Recognition)
- data preprocessing and manifest generation
- model training and inference entry points

For Colab usage, open the notebook:

- `colab_bambara_speech_training.ipynb`

and run the cells in order after uploading your Bambara audio and transcripts.
